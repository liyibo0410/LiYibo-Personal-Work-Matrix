| 编号 | 严重度 | 现象 | 复现 | 疑似根因 | 建议修法（一句话） |
|---|---|---|---|---|---|
| D1 | 高（=X3a） | 列表接口带 `cache-control: public, max-age=300`，**「搜索/刷新」5 分钟内返回浏览器缓存**；删除成功后列表不刷新，重删同一行 → 「删除失败：文档不存在」，用户以为删除功能坏了 | 浏览器里对同一 `/search?keyword=…` 连发 2 次：第 2 次 `transferSize=0`，服务端 `p04.log` 只收到 1 次 | 后端中间件给 JSON 响应加了 `public, max-age=300`（`/search`、`/documents` 都带） | 给动态 JSON 接口加 `cache-control: no-store`（或前端 fetch 带 `cache: 'no-store'`）。**【10:50 复测：已改为 `no-store`，浏览器双发第二条真实回源，根因消除（V13）；「上传→删除→列表刷新」完整观感待本人复核】** |
| D2 | 低-中 | 切片预览翻页不封顶：1 块文档点「下一批」→ 显示「共 1 块，当前第 6~5 块」，列表空白，按钮仍可点 | 文档管理 → 选一个只有 1 块切片的文档 → 预览切片 → 下一批 | `previewNext()` 只做 `offset += 5`，不判断 `total_chunks`/`returned` | 到边界时禁用「下一批」并把 offset 钳到最后一页 |
| D3 | 低-中 | 与知识库毫无关系的问题被误导成「请明确型号」（答非所问，既不拒答也不引用） | 检索问答 → 问「2026 年世界杯冠军是哪支球队？」 | 「确认问题产品」节点在无实体命中时默认走 clarify 分支，缺少「完全无关联→拒答」的兜底 | 澄清前先判「是否有任何召回」：召回为空就直接走拒答话术 |
| D4 | 中 | 服务不可用（502）时，**把 nginx 错误页 HTML 原文贴进回答气泡**（`请求失败：<html><head><title>502 Bad Gateway</title>…nginx/1.24.0…`） | 后端挂掉时在检索问答里提问 | SSE/fetch 失败分支直接把响应文本当答案/错误文案渲染（未截断、未过滤 HTML） | 失败分支只显示「服务暂时不可用（HTTP xxx）」，并剥离/转义非 JSON 响应体 |
| D5 | 低 | 入库中断（Mongo 记录缺失、状态卡「处理中」）的文档**无法删除**（UI 8 次全 404「文档不存在」），列表长期留脏行 | 文档管理 → 找状态「处理中」的行 → 删除 | 列表与删除两侧口径不一致：`DELETE /documents/{task_id}` 找不到记录即 404，而列表仍展示该行（这类行也可能来自列表回落读取） | 删除时若 Mongo 无记录，也应清掉对应磁盘切片备份/文件并把该行从列表移除 |
| D6 | 低 | 检索问答点「清空对话」时若服务端失败，**只清本地、无任何提示**（chat.html 有 alert，console 没有） | 后端挂掉时点 console 的「清空对话」 | `clearQAThread()` 只 `console.warn` | 与 chat.html 对齐，失败时 alert「服务端清空失败，仅清空本地显示」 |
| D7 | 低 | chat.html 的 `👍` 与 `👎` 可以同时处于选中态 | 依次点两个按钮 | 两个 class 独立切换，未互斥 | 二选一互斥 |
| D8 | 低 | console/chat 首屏 console 有 `/favicon.ico` 404（两次） | 打开页面看 console | 未提供 favicon | 加 favicon |
