## 2. 缺陷明细

### 2.1 【高】主图文案 / 视频脚本的「保存」永远失败（合规文案也保存不了），且页面零提示

- **现象**：在「主图」页签编辑主文案后点「保存修改」，无论在「视频」页签点「保存」，最终都跳 `?edit=failed`，改动不落库；页面既没有错误提示也没有成功提示。
- **复现（公网或本地均可）**：
  1. 用 `boss@example.com / Test123456` 登录；
  2. 打开 `/products/2?tab=main-images`，把第一个方案的「主文案」改成任意合规文案（如 `低糖饱腹 独立包装 更方便`）→ 保存修改；
  3. URL 变成 `...?tab=main-images&edit=failed`，表单值仍是旧文案。
- **证据**：截图 agent3-17；`_evidence/button-sweep-20261015/agent3-17-p02-main-images-edit-failed.png`；对照接口层直打同参数 PATCH **HTTP 200**（`patch1-resp.json`）。
- **疑似根因**：`web/src/app/(app)/products/[id]/creative-plans/[planId]/main-image/update/route.ts:15-17`（以及 `video-script/update/route.ts:15-17`）读商品时 **没有带 `authHeaders()`** —— `GET /api/v1/products/{id}` 无令牌返回 **401**，于是每次都走 `redirect(...edit=failed)`。对照：`diagnoses/[diagnosisId]/update/route.ts:15-16` 带了 `authHeaders()`，所以诊断编辑正常。
- **建议修法（一句话）**：给这两个 route 的 `GET /api/v1/products/{id}` 补上 `headers: await authHeaders()`（或复用已有的带鉴权取数函数），并把 422 的 `compliance_blocked` 结果渲染成可见提示。

### 2.2 【高】广告法合规检测只有"接口层"，没有可用的检测 UI；被拦截时页面静默

- **现象**：合规引擎本身是对的（接口返回 422 + `hits[]` 带 `span`/`suggestions`/`legal_basis`），但 P02 前端**没有任何"合规检测/检索"入口**；唯一的接触点是"保存创意方案"这一写操作，失败后 UI 只跳 `?edit=failed`，既不说"被合规拦截"，更不展示命中词/法条。

- **疑似根因**：合规引擎只挂在 `create_creative_plan` / `update_creative_plan` 两个写接口上，前端没有独立检测页/检测按钮；`edit=failed` 分支不消费 422 的 `detail`。

### 2.13 【中，与 `AGENTS.md` ⑩ 一致】P03 编排层确实会把"库内取数"类问题路由到公网搜索

- **现象**：同一条"库里没有的数据"问句里，思考过程出现 **6 次「网络搜索工具」调用**（如 `query:"中国药品零售 2025 门店客流量 中康"`、`query:"沃华医药 心可舒片 价格"`）。
- **本轮为何没出事**：搜索工具**鉴权失败（API key 缺失）**，模型把这句如实写进了结论（"网络搜索：检索工具鉴权失败（API key 缺失），本次未取得带链接的实时外部数据"）——没有拿公开数据冒充库内数据。
- **严重度**：中（风险敞口，不是本轮已发生的错误）；一旦补 key 就会变成"用公网替身数据回答库内问题"。
- **建议修法**：按已写明的修法执行 —— `prompt/prompts.yml` 的 main_agent 加硬规则（库内取数任务不得用公网数据作答），并在编排层对"库内取数"类问题**剥夺该轮的 tavily 路由权**。

### 2.14 【高 · 门禁】P03：图表与"溯源报告"在 UI 上零实现，且免责文案指向一个不存在的组件

- **现象**：页脚常驻「AI 生成的问数结果可能存在偏差，**请以下方溯源报告为准**」，但页面**没有任何"溯源报告"区块**，也没有图表能力；SQL 只能从「查看思考过程」折叠区里读到（见 #75/#76）。
- **证据**：agent3-24、agent3-25、agent3-26。
- **严重度**：**高**（这是 P03 门禁"生成图表 + 带溯源报告"的直接反证；更糟的是文案在承诺一个不存在的东西，属"不诚实呈现"）。
- **建议修法**：二选一 —— ①（推荐）把已有素材渲染出来：SQL 语句 + 行数 + 数据时间范围 + 表名 + 执行耗时 = 一个"溯源"卡片，数值列用内置 SVG/表格画柱状/折线；② 若短期不做，就把这行文案改成与现状一致（例如"结果基于库内只读 SQL，可在思考过程查看全部语句"）。
