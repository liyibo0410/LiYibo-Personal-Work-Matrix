## 五、⚠️ 本次发现的问题（供后续改造参考）

| # | 发现                                                                        | 影响                          | 建议                                                 |
| - | ------------------------------------------------------------------------- | --------------------------- | -------------------------------------------------- |
| 1 | **`/stores`、`/products` 无列表页** —— 目录下只有 `create/` 和 `[id]/`，没有 `page.tsx` | 运营人员无法浏览店铺/商品列表，只能从首页跳详情    | D3 补列表页（表格 + 筛选 + 分页），这是"运营 SaaS"的必备页              |
| 2 | **npm audit：12 个漏洞（1 critical / 10 high / 1 moderate）**                   | 演示若被问"依赖安全"会尴尬              | 跑 `npm audit` 看明细，能修的先 `npm audit fix`，破坏性升级留到独立分支 |
| 3 | 登录路径是 **`/api/v1/auth/login`**（auth router 自带 `prefix="/auth"`）           | 文档/联调易写错                    | 已记录，前端 `lib/` 里的调用以实际为准                            |
| 4 | `.env.sqlite` 与 `local_dev.db` 一并被复制过来                                    | 含**真实模型密钥**（已在 .gitignore）  | 保持 local 使用；提交前确认 `.gitignore` 生效                  |
| 5 | 后端 78 个路径，但前端只覆盖约 5 个页面                                                   | 大量能力（广告实验、创意生成、竞品监控）无 UI 入口 | 是"补前端"的主要工作量，也是演示可讲的"从 API 到产品"的过程                 |
