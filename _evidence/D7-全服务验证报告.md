## 更正记录（2026-10-13 深夜复核）

本报告是 D7 阶段的快照，下面几处与当前代码/证据不符，已就地更正。**结论层面的错误比遗漏更危险**，
因为面试官照着这张表问会得到错误答案：

1. **「P04 向量化 mock（随机向量）」是错的**，而且错的方向是把自己写得比实际更假。
   实测证据：`_evidence/p04/eval_compare_run.log` 第 22-23 行
   `FlagEmbedding.finetune.embedder.encoder_only.m3.runner - INFO - loading existing colbert_linear and sparse_linear`
   （真实 BGE-M3 加载）；第 69-72 行是本地重排模型加载记录，可读部分是
   `path=D:\ai_models\models\BAAI--bge-reranker-large\snapshots\master` 与 `0.8`（该日志的中文正文因
   GBK 控制台写入而乱码，此处不伪造原文）。
   代码侧 `utils/embedding_utils.py` 用的是 `pymilvus.model.hybrid.BGEM3EmbeddingFunction`，
   整个文件没有 `random` 调用。
2. **「P03 LLM 为占位 Key，实际调用会失败」已过时**：D12 查明根因是 `agent/llm.py` 把仓库根算成了
   `projects/`、根 `.env` 从未被读到，两套百炼 Key 本身有效；接通后 P03 能真实出内容并做到「库里没有就拒答」。
   仍未解决的是数据源（3306 没起）与 Tavily。
3. **「P05 全功能真实运行」过度声明**：审批侧是模拟实现，本模块 README 第 302 行自己就是这么写的。
