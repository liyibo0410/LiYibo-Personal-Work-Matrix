## 四、P1 自身缺陷修正（重要）

我在 25 号文 D6 完成判据 #1 写的扫描正则 **有误**：
```
git ls-files -z | xargs -0 grep -E "sk-[A-Za-z0-9]{20,}"
```
该式对 `sk-sp-` / `sk-ws-` **漏报**——`sk-` 后紧跟的 `sp`/`ws` 之后出现连字符会截断 `{20,}` 匹配，
导致 `sk-sp-H.DPXRMP...` 这种 Key **扫不出来**。这正是「测了但测不到缺陷」的典型。

**正确正则**（已用于本次核验）：
```
sk-[A-Za-z0-9][A-Za-z0-9._-]{15,}
```
已同步修正 25 号文 DoD #1 与 21 号文 1.2 自检命令。教训：扫描模式必须覆盖 `sk-`/`sk-sp-`/`sk-ws-` 三种前缀的连字符形态。
