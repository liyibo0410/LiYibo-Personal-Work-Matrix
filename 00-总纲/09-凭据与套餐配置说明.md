# 凭据与套餐配置说明

> 更新：2026-10-12 · 全部结论经**实测验证**，非推测。

---

## 一、重大发现：百炼有**三套互相隔离**的体系

百炼的套餐**不是"一个账号一个 Key"**，而是三套独立的凭证体系，**Key 前缀决定套餐，Key 与 Base URL 严格绑定，混用直接 401**。

| 前缀 | 套餐 | Base URL | 计费方式 | 有效期 | 用途定位 |
|---|---|---|---|---|---|
| `sk-` | **按量付费** | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 按 token 计费 | **无期限** | 任意 API 调用 |
| `sk-sp-` | **Token Plan** | `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` | Credits（算粒） | **按月，到期清零不结转** | 任意 API 调用 |
| `sk-ws-` | **Coding Plan** | `https://coding.dashscope.aliyuncs.com/v1` | 按周/月请求数 | 按月 | ⚠️ **官方限定：仅编程工具使用** |

---

## 二、实测验证结果

| # | Key | 端点 | 结果 |
|---|---|---|---|
| 1 | `sk-ws-`（Coding Plan） | `coding.dashscope.aliyuncs.com/v1` | ✅ **通** |
| 2 | `sk-ws-` | `ws-amdqcpdtt4gdo5ax.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` | ✅ **通**（同属 Coding Plan，是你的专属工作空间端点） |
| 3 | `sk-sp-`（Token Plan） | `ws-amdqcpdtt4gdo5ax...` | ❌ **401 invalid_api_key** |
| 4 | `sk-ws-` | `token-plan.cn-beijing.maas.aliyuncs.com` | ❌ **401 InvalidApiKey** |

**结论**：交叉使用一律失败。**每个 Key 只能配它自己的 Base URL。**

---

## 三、⚠️ 一个重要风险：Coding Plan 不能用来跑应用

官方对 Coding Plan 的定位是 **"Coding tools only"（仅编程工具使用）**。

- ❌ 拿 `sk-ws-` 跑你的十个 AI 应用（客服、RAG、问数…）**可能违反使用条款**
- ✅ 拿 `sk-ws-` 配 **Qoder** —— 这正是它的设计用途

**而 Token Plan（`sk-sp-`）的定位是 "Any API call"，适合跑应用** —— 但它 **2026-10-22 到期**，且**按月清零不结转**。

---

## 四、🔴 最要命的问题：能力不对齐

两个端点提供的模型**不一样**，实测模型列表：

| 能力 | Coding Plan（`sk-ws-`） | Token Plan（`sk-sp-`） |
|---|---|---|
| 主力 LLM | ✅ qwen3.8-max-0902 / glm-5.3 / kimi-k2.8 / step-5 | ✅ qwen3.8-max / glm-5.3 / deepseek-v4.1-flash |
| **Embedding** | ✅ **qwen3.7-text-embedding-flash** | ❌ **没有** |
| **Rerank** | ✅ **qwen3.7-text-rerank** | ❌ **没有** |
| 文生图 | ✅ qwen-image-2.1-pro | ✅ wan2.7-image / wan2.7-image-pro |
| TTS / Realtime | ✅ qwen-audio-3.1-realtime-plus | ✅ qwen-audio-3.0-realtime-plus |
| 多模态 | ✅ qwen3.8-omni-flash | — |

**问题来了**：**P04 RAG 知识库需要 embedding + rerank，而这两个只有 Coding Plan 有，Token Plan 上没有。**

也就是说，靠现有的两个 Key，**跑不通 RAG**（除非用 Coding Plan 的 key，那又踩条款）。

### ✅ 已找到解法（2026-10-12 补充）

**你本地已经有完整的向量模型了**，不需要云端：

| 模型 | 本地路径 |
|---|---|
| `BAAI/bge-m3`（Embedding，稠密+稀疏） | `D:\ai_models\modelscope_cache\models\models\BAAI--bge-m3` |
| `BAAI/bge-reranker-large`（Rerank） | `D:\ai_models\models\BAAI--bge-reranker-large\snapshots\master` |

所以分工调整为：

| 能力 | 走哪 |
|---|---|
| **LLM 生成 / 推理 / 出图 / TTS** | Token Plan（`sk-sp-`）—— 先用着 |
| **Embedding / Rerank** | **本地 BGE 模型**（零下载、零云端依赖、不碰条款） |

**这意味着按量付费不再是"必须马上开通"** —— Token Plan 够用就用着，等额度将尽（或 10/22 到期）再开按量付费接棒。

详见 `10-本地模型资产清单.md`

## 五、✅ 推荐方案：开通按量付费作为应用主力

你说过"没钱可以充"，那这就是最干净的解法：

| 用途 | 用哪个 | 说明 |
|---|---|---|
| **十个项目调用模型** | **按量付费（`sk-`）** | 全模型可用（含 embedding / rerank），**无有效期**，用多少付多少 |
| **Qoder 写代码** | **Coding Plan（`sk-ws-`）** | 正好匹配，不额外花钱 |
| Token Plan（`sk-sp-`） | 保留到 10/22 | 能省一点是一点，到期即废 |

**操作步骤**：
1. 登录百炼控制台 → 地域切到**华北2（北京）**
2. 左侧「API-KEY 管理」→ **创建 API Key** → 归属账号选主账号，权限选"全部"
   - 生成的 Key 以 `sk-` 开头（**不是** `sk-ws-` / `sk-sp-`）
3. 充值：阿里云「费用与成本」→ 账户充值（**建议先充 ¥50-100 试水**）
4. 把新 Key 填进 `面试项目\.env` 的 `LLM_API_KEY`（我会留好位置）
5. 建议开启「**用量预警**」，余额低于阈值时收到通知

> 成本预期：十个项目的开发调试 + 评测，量级在**几元到几十元**。真正的大头是压测，那部分可以用小模型。

## 六、怎么查余额（你的原问题）

### Coding Plan 余额
1. 登录百炼控制台 👉 `https://bailian.console.aliyun.com`
2. 左上角**地域切换到「华北2（北京）」**
3. 顶部导航栏点「**订阅**」→ 选 **Coding Plan**（或进「**我的订阅**」页面）
4. 在 **Coding Plan 页签**看：剩余额度、已用量、**有效期**

### Token Plan 余额
同一页面切到 **Token Plan 页签**即可（看 Credits 余量、重置时间、到期日）
> 你文档里记的是：**Essential 套餐 → 2026-10-22 00:00 到期**

### 按量付费余额（充值后的账户余额）
👉 阿里云「**费用与成本**」→ 账户余额
或百炼控制台的「**用量统计**」页面看调用量与费用

### ⚠️ 重要提醒
**百炼没有公开的余额查询 API** —— 所有 OpenAI 兼容端点都不提供 `/billing` 类接口。
所以：**余额只能人工去控制台看**，程序里查不到。

**替代做法**：让程序在调用失败时识别错误码 ——
- `AllocationQuota.FreeTierOnly` / HTTP 403 → 额度耗尽
- `Arrearage` / 欠费 → 账户欠费

我可以在 `shared/llm-gateway` 里内置这些错误码识别，**额度用完时自动切换备用端点并告警**。

## 七、修正后的 `.env` 配置策略

已按实测结论重写（见 `面试项目\.env`）：

```
【应用主力】 待你开通按量付费后填入 sk- 开头的 Key
  LLM_BASE_URL  = https://dashscope.aliyuncs.com/compatible-mode/v1
  LLM_API_KEY   = （待填，当前为空）

【当前可用】 Token Plan（10/22 到期）
  LLM_BASE_URL_FALLBACK = https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
  LLM_API_KEY_FALLBACK  = sk-sp-...

【编程工具】 Coding Plan（给 Qoder）
  CODING_BASE_URL = https://coding.dashscope.aliyuncs.com/v1
  CODING_API_KEY  = sk-ws-...
```
