## 三、处置动作（按优先级，P0 需逐项批准）

### 第 1 步 —— 立即吊销 / 轮换（🔴 先于一切 git 操作）

> **重要：先吊销，再改代码。** 只改代码不清历史、不吊销，等于泄露没被堵住。

- 登录阿里云百炼控制台 → 找到该 `sk-sp-` Key → **立即禁用/删除**
- 重新签发一把**按量付费 `sk-`** Key（这也是原轮换计划的目标状态）
- 更新以下文件的 `OPENAI_API_KEY`：
  - `projects/p04-rag-knowledge-base/.env`
  - 仓库根 `.env`
- 临时影响：P04 的 LLM / Ragas 在换 Key 前不可用，改完即恢复

### 第 2 步 —— 清除文件中的硬编码

`test_gateway_integration.py:18` 改为从环境变量读取：

```python
# 改前（危险）
REAL_KEY = "sk-..."                      # 明文硬编码

# 改后
import os
REAL_KEY = os.getenv("OPENAI_API_KEY")
if not REAL_KEY:
    raise RuntimeError("请先设置环境变量 OPENAI_API_KEY")
```

同时检查 P02 是否有其它脚本沿用同一写法。

### 第 3 步 —— 清理 git 历史（⚠️ 破坏性，需 P0 明确批准）

改文件只能保证**未来**干净，**历史 commit 里的明文仍在**。
要从历史中彻底抹除，需要重写历史并强制推送：

- 工具：`git filter-repo`（推荐）或 BFG Repo-Cleaner
- 动作：从全部历史中移除该文件的密钥字符串
- 后果：**会改写 commit hash**，需要 `git push --force`
- 影响面：当前仓库只有 P0 一人使用 → 影响可控

> ⚠️ **此操作不可逆。P1 不会在未获 P0 明确批准前执行。**
> 若 P0 选择「不重写历史」，则**必须**完成第 1 步吊销 —— 吊销后历史里的
> 字符串只是一段无效字符，风险归零。这也是可接受的下策。

### 第 4 步 —— 加防复发机制

1. 根 `.gitignore` 补充：
   ```
   .workbuddy/
   **/.workbuddy/
   ```
2. 引入提交前密钥扫描（pre-commit hook 或 CI）：
   对 `sk-` / `sk-sp-` / `sk-ws-` / `api_key=` / `password=` 等模式做拦截
3. 在 `AGENTS.md` 与 README 写明红线：**任何密钥只准放 `.env`，禁止进代码**

## 六、22:15 复验：泄露范围已收敛 —— 但「无敏感文件」的自检结论被证伪

P2（Qoder）在提交前自述：

P1 复验结果：**该结论错误。**

### 证据

```
$ git cat-file -e origin/main:projects/p02-ecommerce-ops-assistant/api/scripts/test_gateway_integration.py
（通过 → 文件在远端）

$ git show origin/main:<path> | grep -cE '^REAL_KEY = "sk-'
1          ← 远端仍含明文 REAL_KEY 赋值
```

**密钥仍在 GitHub 远端，未被处理。**

### P2 为什么漏掉 —— 缺陷类型学第 ⑨ 类（P1 新增）

> **⑨「文件级」自检冒充「内容级」安全审计**
> dry-run 看的是**文件名清单**（有没有 `.env`、有没有 `*.key`），
> 而密钥藏在一个名字完全无害的**测试脚本内部**（`test_gateway_integration.py`）。
> **判据：敏感信息审计必须扫文件内容，不能只看文件名。**
> 附带的错误认知：认为「`.env` 被 ignore 了就安全」——
> ignore 只拦未跟踪文件，**硬编码进已跟踪代码的密钥它管不着**。

### 范围复核（好消息：仅此 1 把）

多厂商凭据模式全扫（已跟踪文件）：

| 模式 | 命中 |
|---|---|
| `sk-` / `sk-sp-` / `sk-ws-` | 3 个文件 |
| `ghp_` (GitHub) / `gsk_` (Groq) / `AIza` (Google) / `xai-` / `AKIA` (AWS) | **0** |

其中 2 个经核实为**占位符**，非真实密钥：

- `p04/README.md` → `sk-your-token-plan-api-key`
- `p04/.env.example` → `sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

→ **真实泄露仅 `test_gateway_integration.py` 一处，范围已收敛。**
