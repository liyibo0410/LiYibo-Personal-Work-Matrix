## 六、Ollama 卸载方案（2.74 GB，在 C 盘）

**已查清**（比猜的准）：
- 安装位置：`C:\Users\23329\AppData\Local\Programs\Ollama`（2,807.6 MB）
- 卸载器：`unins000.exe`（Inno Setup）
- 注册表：`Ollama version 0.32.5`，`QuietUninstallString = "...\unins000.exe" /SILENT`
- 当前**无运行进程**
- 残留：`C:\Users\23329\AppData\Local\Ollama`（4.59 MB）、`C:\Users\23329\.ollama`（0 MB）
- 用户 PATH 含 `C:\Users\23329\AppData\Local\Programs\Ollama`

### 请用**管理员 PowerShell** 执行

```powershell
# 1) 静默卸载（Inno Setup 卸载器，会自弹 UAC 无需你点下一步）
& "$env:LOCALAPPDATA\Programs\Ollama\unins000.exe" /SILENT

# 2) 等卸载器完成（它会把自身复制到 temp 再删自己，所以要等一下）
Start-Sleep -Seconds 25

# 3) 清理残留目录（.NET 原生删除，比 Remove-Item 稳）
foreach ($d in @("$env:LOCALAPPDATA\Ollama", "$env:USERPROFILE\.ollama")) {
  if (Test-Path -LiteralPath $d) { [System.IO.Directory]::Delete($d, $true) }
}

# 4) 从用户 PATH 移除 Ollama 条目
$p  = [Environment]::GetEnvironmentVariable('Path','User')
$np = (($p -split ';') | Where-Object { $_ -notlike '*Ollama*' }) -join ';'
[Environment]::SetEnvironmentVariable('Path', $np, 'User')

# 5) 验证
"--- 剩余检查 ---"
Test-Path "$env:LOCALAPPDATA\Programs\Ollama"
Test-Path "$env:LOCALAPPDATA\Ollama"
```

> **说明**：Ollama 装在 `AppData\Local` 用户目录，卸载器可能不需要管理员；但 Inno Setup 默认请求提权，**用管理员终端最省事**。
> **备选**：如果 `unins000.exe` 报错，走「设置 → 应用 → 已安装的应用 → Ollama → 卸载」，或 `winget uninstall Ollama.Ollama`。
