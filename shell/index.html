P04 检索质量：本地重排 vs 云端重排（零降级对照）

结论：私有化不是免费的。修掉本地重排的量纲缺陷（logits 未归一 → 断崖截断把正分文档静默砍掉）后重跑， 本地 5 项指标仍全面低于云端（Context Precision 差 23.8 pp）、平均延迟慢 2.7 倍，换来的是敏感文档零出网。

真实 / 模拟边界（双处标注）

作品集里最该被追问的部分，先自己交代清楚。

P01 客服 真实：意图三轨道、对话状态机、转人工建单（62 单测）。模拟：订单与商品来自随附的 mock 商城中台 :18081。
P02 运营 真实：登录、RBAC、合规、广告实验、跨模块取数全链路。降级：无 Key 时网关降级 mock 生成，前端标「演示」。
P03 问数 真实：只读 SQL 护栏（DROP/多语句/注释绕过全拦）、执行链路，模型层已接通。未闭环：MySQL(3306)/RAGFlow(9380) 未启动、联网搜索仍是 mock Key；库里没有的数据会明确拒答。
P04 知识库 真实：入库/检索/重排/评测，BGE-M3 本地嵌入 + 本地或云端重排双后端。已修：MCP 联网搜索曾恒 0（异常被静默吞掉）。
P05 合同 真实：规则风险判定、审批流、报告。刻意设计：审批「模拟回写」子系统；LLM 二阶段默认 enabled=false。
P06 数据中台 真实：DuckDB 分层与指标计算。演示数据：自动 seed 的样例集，不是真实店铺。
P07 素材 真实：打标、素材×投放关联报表。模拟：以文搜图用 TF-IDF 而非 CLIP；生图为 mock，UI 挂「Mock 模式」。
P08 切片 真实：批量队列与进度、四维得分构成可解释。模拟：ASR 为模拟文本、评分为规则，无 ffmpeg 真实出片。
P09 考核 真实：会话导入、评分与排行榜。模拟：评分器是规则引擎（Mock LLM），页面挂 Mock Notice。
P10 微调 真实：数据集→训练→评测→注册表生命周期编排、OpenAI 兼容部署形态。模拟：未真实训练（无 GPU），loss 曲线由公式生成，页面与本 README 双处标注。

没有测过的数字就不写：全平台未做并发压测（无 P95 / 错误率）、未测覆盖率； P02 浅色态在 /→/login 跳转时会丢 ?cp-theme（尚未修）。
