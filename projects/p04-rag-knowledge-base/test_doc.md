# H3C LA2608 交换机用户手册

## 产品概述

H3C LA2608 是一款千兆以太网交换机，提供 8 个 10/100/1000Mbps 自适应端口，支持自动翻转（Auto MDI/MDIX）功能。

## 技术规格

- **端口数量**：8 个千兆以太网端口
- **交换容量**：16 Gbps
- **包转发率**：11.9 Mpps
- **MAC 地址表**：8K
- **VLAN 支持**：支持 IEEE 802.1Q VLAN
- **电源**：AC 100-240V，50/60Hz
- **功耗**：最大 15W

## 安装步骤

### 1. 开箱检查

打开包装后，请检查以下物品：
- H3C LA2608 交换机主机 × 1
- 电源线 × 1
- 用户手册 × 1
- 保修卡 × 1

### 2. 放置交换机

将交换机放置在平稳、通风良好的桌面上，确保周围有至少 10cm 的散热空间。

### 3. 连接网线

将网线插入交换机的任意端口，另一端连接电脑或路由器。

### 4. 接通电源

将电源线插入交换机的电源接口，另一端插入电源插座。按下电源开关（如有），指示灯亮起表示正常工作。

## 指示灯说明

| 指示灯 | 状态 | 说明 |
|--------|------|------|
| PWR | 常亮 | 电源正常 |
| PWR | 熄灭 | 未接通电源 |
| LINK | 常亮 | 端口已连接设备 |
| LINK | 闪烁 | 端口正在传输数据 |
| ACT | 闪烁 | 数据活动指示 |

## 故障排查

### 问题：交换机无法开机

**可能原因：**
1. 电源线未正确连接
2. 电源插座无电
3. 电源开关未打开

**解决方法：**
1. 检查电源线两端是否插紧
2. 尝试更换电源插座
3. 确认电源开关处于开启状态

### 问题：端口指示灯不亮

**可能原因：**
1. 网线未插好
2. 对端设备未开机
3. 网线故障

**解决方法：**
1. 重新插拔网线，确保卡扣到位
2. 检查对端设备是否开机
3. 更换网线测试

### 问题：网络速度慢

**可能原因：**
1. 使用了百兆网线
2. 对端设备仅支持百兆
3. 存在网络环路

**解决方法：**
1. 更换为超五类或六类网线
2. 确认对端设备支持千兆
3. 检查网络拓扑，避免环路

## 维护保养

- 定期用干布擦拭交换机表面灰尘
- 避免在潮湿、高温环境中使用
- 不要自行拆卸或维修交换机
- 雷雨天气建议断开电源和网线

## 安全注意事项

1. 请勿在易燃易爆环境中使用本设备
2. 请勿将液体洒在交换机上
3. 请勿堵塞通风孔
4. 请使用原装电源线
5. 长时间不使用时建议断开电源
