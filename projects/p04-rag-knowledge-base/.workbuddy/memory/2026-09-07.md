### 四次：启动端口冲突（Errno 10048，纯环境问题，非代码 bug）
用户两次贴出服务起不来的报错：
- `import_service.py` 起 8000 失败 → 旧实例 PID **61388** 占着 8000 → `Stop-Process -Id 61388 -Force` 释放。
- `query_service.py` 起 8001 失败 → 旧实例 PID **40308** 占着 8001 → `Stop-Process -Id 40308 -Force` 释放。

诊断命令：`netstat -ano | grep ":8000"`（或 `:8001`）查 LISTENING 的 PID；
杀进程：PowerShell `Stop-Process -Id <PID> -Force`；释放后 `netstat` 应无输出。
根因：同端口旧 uvicorn 实例没正常退出（关 IDE/终端未杀干净），不是项目代码问题。
规律：每次改完重跑服务前，先查端口是否被旧实例占着，避免 `Errno 10048`。
