# DESIGN.md — AI 电商运营助手 · 课程结课答辩（深色极简 · 科技蓝）

风格路线：**通用设计原则（universal-only）**。理由：本片是软件项目技术答辩，
不属于「学术论文答辩 / 专业咨询 / 党政汇报」三类垂直场景中的典型学术科研场景；
且用户显式指定了深色极简与主色 `#3370FF`，属用户显式指令，优先级最高。

## 1. 画布与母版（三区，硬约束）

| 母版区 | 垂直位置 | 高度 | 内容规则 |
|---|---|---|---|
| A · 标题块 | 0–120px | **100px**（页 padding 上 20 后起算） | 主标题 36px bold；右侧 kicker 16px muted |
| B · 内容区 | 120–640px | **520px** | 正文、卡片、流程图、巨型数字 |
| C · 页脚条 | 640–720px | **60px** | 左：`AI 电商运营助手 · 课程结课答辩`；右：`NN / 14`，均 14px muted |
| 页面 padding | 上 20 / 下 20 / 左右 64 | — | 100 + 520 + 60 = 680 = 720 − 40 ✅ |

封面 / 结尾页采用自定义版式，可省略 C 区。

## 2. 颜色系统（4 个 hex + rgba 叠层）

| 角色 | 值 | 用途 | 面积 |
|---|---|---|---|
| 背景主色 | `#0B1220` | 全篇底 | ≤ 60% |
| 主色 | `#3370FF` | 焦点、强调条、巨型数字、流程高亮 | ≤ 20%（hero 页）/ ≤ 5%（supporting 页） |
| 文本主色 | `#EAF0F8` | 标题与正文 | 中性 |
| 次要色 | `#7B8AA3` | 页脚、说明、分隔线、弱化文字 | 中性 |

半透明叠层（非新增 hex，允许）：
- 面板：`rgba(255,255,255,0.04)`，1px 边框 `rgba(123,138,163,0.24)`
- 主色浅底：`rgba(51,112,255,0.12)`
- 焦点块外发光：`boxShadow: '0 0 0 1px rgba(51,112,255,0.35), 0 12px 40px rgba(0,0,0,0.45)'`
- 渐变：仅封面与结尾使用 `linear-gradient(135deg, #3370FF 0%, rgba(51,112,255,0) 100%)` 角部装饰，opacity 0.18

禁忌：不出现第二套色板；不出现高饱和撞色；相邻页色彩比例不得雷同。

## 3. 字体系统（2 套家族）

| 家族 | 用途 |
|---|---|
| `'PingFang SC','Microsoft YaHei',sans-serif` | 全部中文标题与正文 |
| `'JetBrains Mono',Consolas,monospace` | 巨型数字、代码/标识符（如 `interrupt`、`tool_gateway`、API 路径） |

| 层级 | 字号 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| 封面主标题 | 76 | bold | 1.15 | 仅 01 |
| 巨型数字/锚点 | 72–110 | bold | 1.0 | 04/11/12 的核心数据 |
| 页面主标题 | 36 | bold | 1.3 | A 区固定 |
| 卡片小标题 | 24 | 600 | 1.4 | 卡片头 |
| 正文 | 20 | regular | 1.6 | 段落 |
| 说明/页脚 | 14–16 | regular | 1.5 | C 区与注释 |

## 4. 信息密度门禁

- 常规内容页留白 ≤ 35%；hero 页（01/11/12）允许 40–45%，留白围绕焦点元素。
- 每页 ≥ 1 个视觉锚点：≥ 72px 巨型数字，或 ≥ 40% B 区面积的主视觉区块。
- 卡片填充率 ≥ 85%；尾部标签条用 `marginTop: 'auto'` 钉底。
- 连续两页禁止同为"等宽卡片横排"版式。

## 5. 配图策略

本片为技术答辩，无具象场景诉求，**全部视觉由结构化元素承担**（分层架构条、流程节点、巨型数字、对比表、证据卡），不使用外部图片。
- L1 主视觉 = 架构分层条 / 流程链路图 / 巨型数字组（占 B 区 ≥ 40%）
- L3 母版徽标 = C 区左侧文字标识（全篇位置一致）
