## 改造：主图生成改为「以商品真实图片为参考」的图生图
- 需求：原来 AI 主图是凭空想象商品，用户要求"根据我的商品图来做"。
- 可行性验证：token-plan 网关的 `wan2.7-image` **支持带参考图**——向 `multimodal-generation/generation` 的 `input.messages[0].content` 传 `[{"image": <url 或 base64 data URI>}, {"text": ...}]` 即可；本地文件用 `data:image/jpeg;base64,...` 能直接吃（无需公网可访问 URL）。带参考图时建议 `parameters.prompt_extend=false`，否则扩写会冲掉"保持商品外观一致"的约束。
- 代码改动：
  - `app/services/image_generation.py`：新增 `_resolve_reference_image()`（公网 URL 原样；本地 `/uploads/...` 用 Pillow 压到 ≤1280 后转 base64 data URI）；`_create_dashscope_wan26_image(prompt, settings, reference_image=None)` 支持参考图；`generate_main_image_asset(..., reference_image=None)` 在有参考图时前置"严格保持商品外观一致"的指令。
  - `app/services/generation_jobs.py`：`_generate_asset` 主图分支自动取 `Product.images[0]` 作参考图（`_product_reference_image()`），商品没图则退回纯文生图。
- 依赖：新增 **pillow**（已写入 `pyproject.toml` + `requirements.txt`，用 `uv pip install --python .venv/Scripts/python.exe pillow` 装入 api/.venv，12.3.0）。
- 验证脚本 `scripts/verify_ref_image.py`：用 plan 41 + 商品 #4 的 `tai7-green-urban.png` 作参考 → 出图保留真实绿色钛7外观 + 卖点文案，存 `/uploads/generated/main-image-plan-41-d0a2350e92e04cb0b2656c9adb6149c6.png`。
- 注意：改动需**重启后端**才在 UI 生效（run_local_dev 未开 reload）。参考图取 `images[0]`，用户可调整商品图片顺序来换"基准图"。
- 另修：`app/main.py` 增加 `mimetypes.add_type("image/webp", ".webp")` / avif（否则 StaticFiles 以 octet-stream 返回，重启后生效）。
