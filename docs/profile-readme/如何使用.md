# 如何使用：把这四个文件变成 GitHub 个人主页

本目录（`docs/profile-readme/`）里的文件，最终要**逐字复制**成 `liyibo0410/liyibo0410` 这个仓库的根目录文件。
它们和主仓库（`yunshu-ai-portfolio`）的关系只有一处：内容口径一致。文件本身是自包含的 —— 图片全是同目录相对路径，不引用主仓库里的任何东西。

## 一、文件映射表

| 本目录文件 | 目标位置 | 作用 |
|---|---|---|
| `README.md` | profile 仓库 **根目录** `README.md` | 个人主页正文 |
| `banner.svg` | profile 仓库 **根目录** `banner.svg` | 浅色（默认 `prefers-color-scheme: light`）横幅 |
| `banner-dark.svg` | profile 仓库 **根目录** `banner-dark.svg` | 深色横幅，README 里的 `<picture>` 会自动切换 |
| `如何使用.md` | **不需要上传**（也可以顺手放进仓库，不含隐私内容） | 就是本说明 |

路径必须保持同级：`README.md` 里写的是 `./banner.svg` 与 `./banner-dark.svg`，把 svg 放进子目录就会 404。

## 二、前提条件（GitHub 的硬规则）

1. **仓库必须是 public**。私有仓库的 README 不会显示在个人主页顶部。
2. **仓库名必须与用户名同名**，即 `liyibo0410/liyibo0410`。名字对不上，README 也不会被挂到个人主页。
3. 文件必须在**仓库根目录**，不能是 `docs/README.md`。
4. 满足以上三点后，打开 `https://github.com/liyibo0410` 即可在顶部看到这份 README；README 里图片是相对路径，因此在 GitHub 上渲染出的就是仓库里的那两个 svg。

## 三、上传方式（任选其一）

- **网页上传**：在 profile 仓库页面 → `Add file` → `Upload files` → 把 3 个文件拖进去（`README.md` 同名会提示覆盖，确认即可）→ Commit。
- **命令行**（主控或你自己在克隆下来的 profile 仓库里执行，本目录不负责提交）：
  - 把 `README.md`、`banner.svg`、`banner-dark.svg` 复制到 profile 仓库根目录；
  - 然后按你自己的节奏 `git add` / `commit` / `push`（**本目录不代做任何 git 操作**）。

## 四、本地预览

- **svg**：直接双击用浏览器打开，或把路径拖进浏览器地址栏。两者都是 `1280×300` 的独立矢量图，不依赖字体文件、不依赖网络（没有外链图片和外链字体）。
  - 想验证**深色版**：打开 `banner-dark.svg` 即可看深色效果；想验证 README 的自动切换，把系统主题切成深色再刷新 GitHub 个人主页。
- **README.md**：在 VS Code / Qoder 里 `Ctrl+Shift+V` 打开 Markdown 预览；注意预览里的 `<picture>` 也会按主题切换横幅。
  - 预览时若徽章显示为空白，是 shields.io 被网络挡住了 —— README 里已写好纯文本兜底那一行，信息不会丢。

## 五、维护提示

- **徽章依赖第三方服务**：所有 `img.shields.io` 图片都是 shields.io 的静态徽章，不涉及动态统计卡；如果站点不可达，README 中紧随其后的纯文本技术栈列表仍然完整。
- **深色横幅的小字**：按设计令牌要求，强调色在深色底上仍是同一个品牌蓝 `#3370FF`（`10 模块 · 4 层 · 731 passed · 证据可复核` 那一行），字重已加到 600 以保证可读性。要改配色，请对照主仓库 `shared/ui-kit/tokens.css`，别在本目录自创色值。
- **不要在个人主页放的东西**：演示账号与口令（README 里已改成「见仓库 README」）、手机号（本次未放，只在 README 正文末尾留了一行 HTML 注释提醒你决策）。
- **改文案的边界**：README 里的数字（10 模块 / 4 层 / 15 进程 / 731 passed / 6 条 ADR / 4 条调用链路）都来自主仓库实测，改动前先回主仓库 `_evidence/` 核对，否则个人主页会比主仓库先失真。
