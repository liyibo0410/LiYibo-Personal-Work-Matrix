# 0006 · P05 合同审查的零第三方依赖例外

- 状态：Accepted
- 日期：2026-10-12

## 背景

技术规范默认 Python 侧 FastAPI + Pydantic v2 + SQLAlchemy + Alembic，包管理强制 uv。但 P05「衡鉴」合同风险审查的核心价值是**确定性**：风险规则、条款抽取、评分必须可复现、可解释、可离线演示，不引入模型/数据库版本漂移。

## 决策

P05 作为**有意的例外**：`projects/p05-contract-review` 仅用 Python 标准库实现（HTTP 服务 + 规则引擎 + SQLite 通过内置 `sqlite3`），PDF 报告走系统浏览器无头打印通道，扫描件 OCR 走 Windows 内置引擎。`run.py` 直接 `python run.py` 启动，端口 8770 注册进 SERVICE_REGISTRY。

## 后果

- (+) 零依赖、秒级启动、结果确定可复现，契合「风险打分可解释可追溯」的验收门禁。
- (−) 与其他模块的 FastAPI/uv 栈不一致，`start-all.bat` 需为它单列一条 `python run.py`（不走 `uv run`）。
- (−) 鉴权/静态托管自成一套（`/shared` 设计系统接入方式同静态模块），与其他 FastAPI 模块的实现细节不通用。
