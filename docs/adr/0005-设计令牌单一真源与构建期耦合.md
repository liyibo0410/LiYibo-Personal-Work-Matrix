# 0005 · 设计令牌单一真源与两类前端的注入方式（及耦合代价）

- 状态：Accepted（2026-10-13 修订，见下）
- 日期：2026-10-13

## 背景

规范要求「UI 统一：`shared/ui-kit` 提供主题变量与组件，禁止各模块自造一套」「统一白底 + 单一强调色」。真源是 `shared/ui-kit/tokens.css`（`--cp-*`）。但前端分两类，注入方式必须不同：

1. **静态托管模块（P04~P10）**：FastAPI 运行时把仓库根 `shared/` 挂到 `/shared`，页面 `<link>` 引入 `tokens.css`，`:root` 重指向 `var(--cp-*)`，`body` 带 `cp-app data-cp-module`。
2. **构建型模块（P01/P02/P03）**：由 Vite/Next 打包，自身源没有 `/shared`，令牌必须**打进 bundle**。

## 决策

- 静态模块：运行时挂载 `/shared`（无构建期耦合）。
- 构建模块：以 **CSS 模块 `import`** 引入 `tokens.css`（实测跨根 `@import` 会被 rolldown-vite / Next 静默丢弃），再把模块局部 `:root` / Tailwind `@theme` 核心色重指向 `var(--cp-*)`。
  - P01/P03（Vite）：从 `src/main.ts|main.js` 直接 `import '…/shared/ui-kit/tokens.css'`（相对路径按目录深度）。
  - P02（Next）：Next 禁止 import 项目根（`web/`）之外文件 → 新增 `web/scripts/copy-tokens.mjs`，`predev/prebuild` 构建期把令牌**复制**进 `web/src/app/tokens.css`（GENERATED 头，真源仍在仓库根），`layout.tsx` 引入。
- 每模块加轻量主题桥：`data-theme`（html）+ `cp-app data-cp-module`（body）+ 监听外壳 `cp:theme`。P02 桥只同步主题（认证见 0003 例外）。

## 后果 / 耦合代价（诚实记录）

- (+) 核心配色/字体真正单一真源：改 `tokens.css`，静态模块运行时即变，构建模块下次构建即变。
- (−) **构建模块存在「构建期耦合」**：令牌被复制/内联进 bundle，改 `tokens.css` 后**必须重新构建**才生效；P02 的 `tokens.css` 是生成物，直接编辑无效（下次 prebuild 覆盖）。
- (−) 无对应令牌的派生色阶（P02 brand 100~400/700~900、个别填充档）与图表 JS 里的十六进制数组、内联 SVG `stop-color` 仍为字面量（属性无法取 `var()`），值等于品牌蓝但不随令牌翻转；浅色模式下这些不翻转（平台默认深色）。
- (−) Vite 侧相对路径按目录深度写死（`../../../..`），移动入口文件层级需同步改。
