## 2. README 里怎么引

浅色 / 深色跟随系统主题（GitHub 会把这两个文件分别代理给深浅色读者）：

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="docs/assets/github/banner-dark.svg">
  <img src="docs/assets/github/banner.svg" width="1280"
       alt="云枢智能 CloudPivot · AI 电商运营中台 —— 十个 AI 能力模块，合并成一套统一系统">
</picture>
```

只想用一张（浅色）：

```markdown
![云枢智能 CloudPivot · AI 电商运营中台](docs/assets/github/banner.svg)
```

要点：

- 显式写 `width="1280"`，避免 GitHub 按容器宽度把 1280×320 的图拉变形；
- `alt` 写全称，读屏与图片加载失败时都有意义；
- 社交预览**不要**用 `social-preview.svg` 去传 —— 上传入口只收 PNG/JPG。

## 3. 怎么重新生成

```powershell
# 在仓库根目录
python -X utf8 _tools\make_github_assets.py              # 重绘 social-preview.png + 全量自检
python -X utf8 _tools\make_github_assets.py --check-only # 只自检，不重绘
```

脚本做三件事，退出码 0 = 全 PASS，1 = 有 FAIL：

1. **从零重绘 `social-preview.png`**（Pillow 直绘，2 倍超采样后 LANCZOS 降采样；不调用任何 SVG 渲染器），
   打印尺寸与字节数；
2. **校验三张 SVG**：`width/height/viewBox`、XML 良构性、必需文案（整串 + 关键文本节点）、
   XML 注释里不得出现 `--`、**封面不含入口地址**（无 IP / 端口 / 演示 URL / 「在线演示」措辞）、
   安全清洗红线、`role="img"` / `<title>` / `<desc>`、`font-family` 属性列表、UTF-8 无 BOM；
3. **逐条文本边界检查**：按「中文 1.0em、英数 0.55em」的保守口径估算每条文本宽度，
   再按 `text-anchor` 算出左右边界，断言全部落在 ≥24px 边距内（同时校验垂直方向不溢出）。

当前共 **42 项检查**，全 PASS、退出码 0。

字体：默认用 Windows 自带的 `C:\Windows\Fonts\msyh.ttc`（常规）与 `msyhbd.ttc`（粗体）。
候选字体逐个探测（**文件存在 → 能加载 → 12 个汉字能渲染出互不相同的字模**），
全部不可用时**直接报错退出**（退出码 2），绝不静默输出豆腐块。

```powershell
# 换字体（例如非 Windows 机器）
$env:CP_ASSET_FONT_REG  = "D:\fonts\NotoSansSC-Regular.otf"
$env:CP_ASSET_FONT_BOLD = "D:\fonts\NotoSansSC-Bold.otf"
python -X utf8 _tools\make_github_assets.py
```

三张 SVG 是**手写单文件**（不是脚本生成的），改文案/坐标请直接编辑 SVG，
然后跑一次自检确认没越界 —— 脚本只负责 PNG 重绘与校验，不会覆写 SVG。

## 4. GitHub 侧渲染注意事项

### 4.1 会被 camo 代理 + 安全清洗

README 里的图片走 GitHub 的 camo 代理，SVG 会被做安全清洗。因此本目录的 SVG 全部遵守：

- **不含** `<script>`、`<foreignObject>`、`<style>`、`<use>`、`<image>`、`@import`、`xlink:href`、外链字体、外链图片；
- 文字**一律用 `<text>`**，不做路径化（`<path>` 化文字）—— 代价见 4.2；
- 颜色全部写成 `fill="#RRGGBB"` 字面量，不用 CSS 变量（`var()` 在 `<img>` 上下文里没有宿主可继承）；
- 背景纹理是**纯几何**（64px 网格 + 四层色块），没有渐变、滤镜、毛玻璃 —— 既符合设计纪律，也避开清洗器对 `filter`/`mask` 的不可预测处理。

### 4.2 不嵌字体带来的取舍（已知且刻意）

`font-family` 用的是属性列表
`'Microsoft YaHei','PingFang SC',Inter,-apple-system,'Segoe UI',sans-serif`，
**不嵌字体**。所以在 Windows 上渲染成微软雅黑，macOS 上退回苹方，两者字形与字宽略有差异。

因为宽度估算是按「中文 1.0em」算的 —— 这是几乎所有中文字体的实际全角宽度，
且每条文本两侧都留了 ≥24px（实际多数 ≥40px）的余量，所以换字体的机器上也不会越界。
换个说法：**不是为了好看而留白，是留了回退空间。**

### 4.3 深色主题

SVG 在 `<img>` 里**拿不到宿主页面的 CSS**，所以不能在文件内部做主题切换。
深色读者靠 README 里的 `<picture>` + `<source media="(prefers-color-scheme: dark)">` 换成 `banner-dark.svg`。

### 4.4 社交预览

- 入口：仓库 **Settings → General → Social preview → Edit → Upload an image**；
- 该入口只接受 **PNG / JPG**，建议 **1280×640**、体积 < 1 MB（本文件 130.3 KB）；
- 传上去的是仓库级资源，**不在 git 里** —— 想改就得重新上传，所以源文件 `social-preview.svg` 与
  可复跑脚本一并留在仓库，保证「上传的那个 PNG」可复现。

### 4.5 封面不放任何入口（硬约束）

头图与社交预览卡上**不出现 IP、端口、演示 URL**，也不用「在线演示」这类措辞。

原因：公网入口是 SSH 反向隧道 + 服务器 nginx 路径分流，**不是常态在线** ——
2026-10-15 同一个入口 09:40 可正常返回、09:54 复测全部 502（nginx 还在，上游隧道已断）。
封面是仓库的第一印象，把入口写上去等于**承诺一个随时会打不开的地址**。

入口的正确落点：**仓库 README 正文**（标注「按需开启」）与 `online-demo.md`（记录逐次实测）。

脚本里守着这条线的是 `ENTRY_PATTERNS` 四条常驻检查（IPv4 / 外链 URL / 带端口地址 / 「在线演示」措辞），
任一命中就 FAIL。**想加回入口，得先改掉那四条检查** —— 这就是把决定写进代码而不是写进约定。

## 9. 已知边界（如实记，不美化）

1. **封面已按机主决定去掉在线演示地址（2026-10-15 改）。** 原先三张图的右上角各写过一处
   `39.96.200.45:8070`，理由是「实测可打开」；但同一入口 2026-10-15 09:40 正常、09:54 复测**全部 502**
   （服务器 nginx 在、上游 SSH 反向隧道已断，逐条记录见 `online-demo.md`），
   把地址放在封面上等于承诺一个打不开的入口 —— 机主决定删掉，改为**不承诺入口**的实跑信息。
   现在三张图里**没有任何 IP / 端口 / 演示 URL**，脚本 `ENTRY_PATTERNS` 会把这三类字串当作常驻红线拦住复发；
   演示入口只在仓库 README 第十.6 条与 `online-demo.md` 里出现，且明确写成「按需开启、演示时段有限」。
   本机入口是 `http://127.0.0.1:8800`（`start-all.bat` 一键起）。
2. **PNG 是 Pillow 直绘，不是 SVG 渲染。** 两者同布局同文案，但**逐像素不等于**：
   Pillow 不支持 `letter-spacing`，`CP` 字标少了 0.5px 字距；粗体由 `msyhbd.ttc` 提供，
   浏览器可能对部分字形做合成加粗。观感一致，不要拿它们做像素级 diff。
3. **`social-preview.png` 133.8 KB（137,040 字节），不是最小体积**。为保住中文小字的清晰度用了 2 倍超采样；
   压到 8-bit 调色板 PNG 能更小，但中文细笔画的锯齿会变明显 —— 取舍放在清晰度一侧（限额是 400 KB）。
4. **没有做「小红书 / 微信 / Twitter 大卡」等其它尺寸**，只做了任务要求的
   1280×320 头图（深浅两版）与 1280×640 社交预览。
5. **深色版只有头图，没有深色版社交预览**：社交预览由 GitHub 自己的界面承载，
   上传入口不区分主题，多做一个深色 PNG 没有落点。
