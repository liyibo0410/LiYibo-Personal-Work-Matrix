03 — 调用闭环

口径只有一份，数据真的在模块之间流动

跨模块取数走真实调用，降级态用「少返回」而不是「编一个」——响应里直接不含该字段，绝不伪造。以下为已实测的真实调用链路。

P02 → P06 实时指标

运营助手向数据中台取实时大盘指标，正常路径真实调用；上游不可达时降级返回，不补全假数据。

P09 → P01 真实会话

销售考核通过 HTTP 真实拉取客服模块的会话记录（实测分值 65.5 / 70.5），而非读本地快照。

P02 → P07 素材推送

运营生成的素材经 POST /api/v1/ingest 真实推送到素材中心入库，形成能力层回流。

04 — 决策记录

六条架构决策（ADR）

关键选型均有据可查，避免「能跑就行」式的隐性债。

0001

微前端外壳而非单体合并

三类前端栈异构（Next.js / Vue+Vite / FastAPI 直挂），合并等于重写四个前端；代价是主题与令牌只能运行时同步。

0002

服务注册表＝端口单一真源

起因是一次真实故障：前端把后端写成 8000（实为 8030）。跨模块调用禁止硬编码端口。

0003

统一认证与令牌下发

外壳签发 HS256、postMessage 下发；P02 保留自身 Cookie RBAC——有意识的例外。

0004

跨模块真实调用，降级不伪造

降级态用「少返回」而非「编一个」：degraded=true 且响应里直接不含该字段。

0005

设计令牌单一真源

静态模块运行时挂 /shared，构建型模块构建期内联 + 主题桥；代价是改色后必须重新构建。

0006

P05 零依赖例外

客户机 python run.py 即跑，不必先装 Docker。风险打分要的是确定性与可复现。

真实与模拟的边界，写在这里

本作品集的已知未闭环（截至 2026-10）
