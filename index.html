SECTION 02 / LIVE DEMO

在线实机

整平台通过 SSH 反向隧道 + nginx 路径分流对公网开放，十个模块与外壳网关在同一入口后面连着操作。

http://39.96.200.45:8070
演示期临时开放，非 24h 在线 —— 访问前建议先联系确认隧道已开启；演示账号 owner / owner123
架构：访客 → nginx 路径分流（/pXX/ 精确 location + Cookie 路由兜底）→ SSH 反向隧道回环端口 → 本地各模块。
断线自愈：保活脚本 3s 重连 + sshd 死会话 30s 回收 + 看门狗 15 分钟巡检，单次掉线对访客的影响压到 ≤35 秒。
SECTION 03 / DECISIONS

六个工程决策（ADR）

每条都是已落地的决策，连同代价一起写 —— 完整版见仓库 docs/adr/。

ADR-0001
微前端外壳而非单体合并：三类前端栈异构（Next.js / Vue 3 + Vite / FastAPI 直挂），合并等于重写四个前端；代价是主题与令牌只能运行时尽力同步。
ADR-0002
SERVICE_REGISTRY 端口单一真源：跨模块调用禁止硬编码端口。起因是一次真实故障：P03 前端把后端写成 8000，实为 8030。
ADR-0003
统一认证与令牌下发：外壳网关签发 HS256、postMessage 下发，模块只校验不重造登录；P02 保留自身 Cookie RBAC 是有意识的例外。
ADR-0004
跨模块真实调用与降级不伪造：取数走真实 HTTP，降级态「少返回」而不是「编一个」—— degraded=True 时响应里直接不含 metrics 字段。
ADR-0005
设计令牌单一真源：静态模块运行时挂 /shared，构建型模块构建期内联 + 主题桥；代价是改色后必须重新构建才生效。
ADR-0006
P05 零依赖例外：合同审查只用标准库，客户机免装 Docker 即跑 —— 风险打分要的是确定性与可复现，比「栈统一」更重要。
